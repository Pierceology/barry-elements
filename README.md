# barry-elements

Custom elements for barryframing.com, served from GitHub Pages so a push goes
live without opening the Wix editor.

| file | Wix tag |
|---|---|
| `barry-frame-wall.js` | `barry-frame-wall` |
| `manager.js` | `barry-manager` |

Wix still owns the domain, the pages, the backend and the CMS. This repo owns
what draws on screen.

- https://pierceology.github.io/barry-elements/barry-frame-wall.js
- https://pierceology.github.io/barry-elements/manager.js

Rollback: in the Wix editor set the element source back to the site file under
`src/public/custom-elements/`. Nothing else changes.
